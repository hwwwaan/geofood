# 그날 영광에서는

생년월일을 넣으면 그 무렵 영광에서 나던 먹거리 하나를 배정하고,
마지막에 영광 먹거리 22종을 전부 펼쳐 **굴비가 그중 하나임**을 보여주는 정적 웹사이트입니다.

발표: 2026년 8월 24일

## 로컬에서 보기

`fetch`로 `items.json`을 읽기 때문에 파일을 더블클릭해서 열면 동작하지 않습니다.
간단한 서버를 하나 띄우세요.

```bash
python3 -m http.server 8000
```

띄운 뒤 브라우저에서 `http://localhost:8000` 을 엽니다.

배정 로직만 확인할 때는 서버 없이 돌려도 됩니다.

```bash
node sim.js
```

`?mode=inverse` 를 결과 주소에 붙이면 인지도 역가중으로 뽑습니다. 기본은 균등입니다.

## GitHub Pages 배포

빌드가 없습니다. 이 폴더를 그대로 올리면 됩니다.

1. 새 저장소를 만들고 이 폴더의 파일을 푸시합니다
2. Settings › Pages › Source 를 `main` 브랜치 루트로 지정합니다
3. `https://<계정>.github.io/<저장소>/` 로 열립니다

`items.json` 경로는 `import.meta.url` 기준이라 저장소 이름이 붙은 하위 경로에서도 안 깨집니다.

**용량** — 전체 55KB 안팎입니다. 웹폰트를 받지 않고 외부 스크립트도 없어서
QR로 접속해도 첫 화면이 바로 뜹니다. Pretendard가 깔린 기기면 Pretendard로,
아니면 기기 기본 한글 폰트로 그립니다.

## 지켜야 할 것

`00-brief/SPEC.md` 의 설계 원칙 여섯 개를 어기지 마세요. 특히 두 개입니다.

- **생년월일은 예측이 아니라 배정 장치입니다.** 취향을 묻기 시작하면 인기 품목에 노출이 더 몰립니다
- **굴비는 배정에서 빠지되 목록에는 남깁니다.** 빼면 굴비를 부정하는 게 되고,
  넣어야 "굴비 뒤에 21개가 더 있다"가 됩니다

사주·운세 어투를 쓰지 않습니다. 근거는 사주가 아니라 수확기입니다.

- 22종 중 15종의 수확기가 영광군 원자료로 확인되지 않았습니다 (화면에 「확인 중」 배지)
